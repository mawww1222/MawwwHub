## 📖 Tentang

**MawwwHub** adalah UI Hub untuk Roblox yang dibangun dengan **Library Custom** (self-hosted, tanpa dependensi eksternal). UI dibuat dengan tema **Purple Colorful** dengan border gradient warna-warni di setiap tombol.

- ✅ Support **PC & Mobile**
- ✅ Toggle keybind: **LeftControl**
- ✅ Draggable toggle button
- ✅ Save / Load config otomatis
- ✅ Theme preset (Default / Pink / Cyan / Dark)
- ✅ Notification system
